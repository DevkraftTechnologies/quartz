# Quartz (Digital Garden)

## What This Repo Is

Hugo-based personal knowledge base / digital garden. Published at https://quartz.devkraft.in/

## Repo Structure

```
config.toml          Hugo config (Dracula syntax highlighting, git info enabled)
content/notes/       72 markdown files covering generative AI topics
content/templates/   Note templates
assets/              JS, CSS, indices
layouts/             Hugo templates
static/              Static files
```

## Content Focus

Generative AI and modern ML: LLMs, transformers, GANs, ChatGPT, prompt engineering, RAG, vector databases, LangChain, agents, memory systems. Well-organized with timestamps.
